# Judge testing instructions

## Copy for the private Devpost testing field

Open [RealityFork](https://realityfork-final.onrender.com/?preview=atlas) in a desktop browser with WebGL for the 3D chapter. If the host says it is waking up, leave the tab open until RealityFork loads.

1. Click the **The Hollow** island on the landing screen. With a keyboard, focus **Enter The Hollow** and press Enter or Space. On touch, tap the island twice. Use WASD or arrows to walk, Q/E to turn, and F or a visible interaction prompt to interact. On a phone, use the on-screen controls.
2. Enter **The Whispering Bookshop**, read the Keeper’s Desk, then choose **Begin Mara’s Story**. Pick a decision and confirm it. Visit the Whispering Well when the ledger offers it. Make a second decision, fork at that decision, and open **Compare timelines**. The Forking Mirror lets you inspect the consequences of both saved story paths.
3. Select **Explore Your Own What-If** or return to the Multiverse. The **Household solar panels** example and **Start a blank map** work without a code. From the solar example, choose **Explore another path from here** to change an assumption and use **Compare** to inspect the result.
4. To try the optional AI planner, enter a fictional question such as “What if I kept my neighbourhood bookshop open on fewer days?” and select **Explore possibilities**. If prompted for **Judge access code**, use the code supplied privately in this field. Pick a draft, change an assumption or add context, then use **Ask AI to take another look** when available. Review the proposed update before applying it.
5. If AI is unavailable or a quota is reached, use the built-in example or the manual planner to complete the comparison. If 3D is unavailable, open [the standard planner](https://realityfork-final.onrender.com/) for equivalent planner actions.

## Maintainer review before submitting

Enter the actual judge code only in the restricted Devpost field after confirming the hosted provider and testing the private credential. The access implementation has an end date of January 30, 2027 at 12:00 UTC, which is after the January 29 judging cutoff. Configured request limits and provider availability can still restrict judge evaluation. Confirm that judges can exercise the submitted AI flow through the entire judging period and resolve any uncertainty about the rules with the organizer before submission.
